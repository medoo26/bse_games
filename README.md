# ركن ابتكارات المعلمين بالذكاء الاصطناعي

منصة ويب بسيطة تتيح للمعلمين عرض مشاريعهم وابتكاراتهم في مجال الذكاء الاصطناعي، مع إمكانية رفع الملفات واستعراضها وإدارتها من لوحة تحكم خاصة.

## المميزات
- واجهة عربية بالكامل (RTL) ومتجاوبة مع الجوال
- عرض المشاريع في معرض منظم
- رفع الملفات وتخزينها عبر Supabase Storage
- لوحة إدارة لمراجعة المشاريع وتعديلها

## التقنيات
- HTML / CSS / JavaScript (ملف واحد)
- [Supabase](https://supabase.com) لقاعدة البيانات والتخزين
- خط Cairo وأيقونات Font Awesome

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشره عبر GitHub Pages.

## الإعداد
عدّل الثوابت في أعلى الملف:
- `SUPABASE_URL` و `SUPABASE_ANON_KEY` ببيانات مشروعك
- `STORAGE_BUCKET` و `PROJECTS_TABLE` حسب إعدادك

> تنبيه: فعّل سياسات RLS في Supabase، ولا تعتمد على رمز PIN وحده لحماية لوحة الإدارة.
